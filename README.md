# Badminton Career

A browser-based badminton career management simulator.

## Play locally

Open `index.html` in a modern browser. No build tools or dependencies are required.

## First playable prototype

- Create your player profile.
- Manage weekly training and recovery.
- Track energy, form, confidence, attributes and ranking points.
- Enter tournaments and simulate match outcomes.
- Progress through the season.

## Project direction

The goal is to build a detailed career mode focused on the journey from junior badminton to the international senior circuit. Future systems can include doubles partners, coaches, clubs, sponsorships, national-team selection and a full tournament calendar.

## Tech

Vanilla HTML, CSS and JavaScript.
